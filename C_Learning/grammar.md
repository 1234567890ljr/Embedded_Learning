⭐比如想找一个数组中的最大最小值：
```c
#include <stdio.h>
void minmax(int a[], int len, int *max, int *min);

int main(void)
{
    int a[] = {1,2,3,4,5,6,7,8,9,12,13,14,16,17,21,23,55,};
    int min,max;   // 两个空盒子，准备存结果 !
    //主函数中调用函数，参数传地址 &min &max !
    minmax(a, sizeof(a)/sizeof(a[0]), &min, &max);
    //注意：a = &a[0] = a[] 传入的是数组a的首地址！
    //sizeof(a)/sizeof(a[0]) 算长度!
    printf("min=%d,max=%d\n", min, max);
    return 0;
}
//函数定义参数：传入指针，注意数组要单独传长度，a[]=*a !
void minmax(int a[], int len, int *min, int *max)
{
    int i;
    *min = *max = a[0];

    for ( i=1; i<len; i++ ) {
        if ( a[i] < *min ) {   //a[i]的本质等价于*(a + i) !
            *min = a[i];      
        }
        if ( a[i] > *max ) {
            *max = a[i];       
        }
    }
}
```

指针运算：
`指针 + n` = 原地址 + n × sizeof (指针指向类型)
`1个字节是内存最小单元，1个char占1个字节，1个Int占4个字节`
`字节是最小内存格子；而数组元素是 “打包好的块”，char 一块 = 1 格，int 一块 = 4 格。指针 + 1，是跳到下一块，不是下一格！`
应用：`*(p+n)=a[n]`
指针相减： = n 不是地址相减得到的那个数
`*p++`:先读当前位置的值，读完 p 往后挪一格(数组遍历)
